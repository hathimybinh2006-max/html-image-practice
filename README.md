# Thực hành thẻ hình ảnh trong HTML (<img>)

Bài thực hành luyện tập sử dụng thẻ `<img>` để hiển thị hình ảnh trên trang web.

## Nội dung bài tập
- File chính: `index.html`
- Thẻ `<img>` chèn ảnh với các thuộc tính:
  - `src`: Đường dẫn URL của hình ảnh
  - `alt`: Mô tả nội dung hình ảnh ("Cảnh quan thiên nhiên núi non và hồ nước tuyệt đẹp lúc hoàng hôn")
  - `width`: Kiểm soát kích thước hiển thị của hình ảnh
